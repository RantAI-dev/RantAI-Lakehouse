# Which acceptance gates a changed file can affect (OPS-25).
#
# This is the only place gate membership is written. `scripts/ci/detect_change_scope.sh`
# reads it to select gate groups for a pull request, `scripts/ci/required_gate.sh`
# reads the `group` lines to know when a skipped gate is acceptable, and
# `ops/lint/check_gate_groups.py` checks both against `.github/workflows/ci.yml`.
#
# Format, one entry per line, `#` starts a comment and blank lines are ignored:
#
#   group <name> <job> [<job>...]   the jobs of one gate group (one line per group)
#   path <pattern> <groups>         the files that select that group
#
# <groups> is a comma list of group names, `all` (every group) or `none` (no gate).
# Patterns are bash `[[ $file == $pattern ]]` globs, so `*` also matches `/`
# (one pattern covers a whole tree: `ops/g4/*` is `ops/g4` and everything below it).
#
# THE FIRST MATCHING `path` LINE WINS. Specific lines therefore come before the
# catch-alls: `rust/crates/lakehouse-iceberg/tests/g1_*` before `rust/crates/*/tests/*`,
# the `ops/g6` exceptions before `ops/g6/*`, and every `ops/*`/`rust/*` rule before
# the shared `all` lines at the end.
#
# A changed file that matches no `path` line selects every group: an unknown path
# means everything (fail closed, OPS-25 D2/D5). It is logged as
# `Unmapped file: <path> (selecting every gate group)`.
#
# A pull request runs only the gates its files can affect. Every gate still runs
# in the nightly full run and on `workflow_dispatch`; that run is the backstop
# that catches a gate a pull request did not run. The owner accepted that `main`
# may be red until then (docs/CI.md, "Gates by path").

# ── Shared: any change here can change any gate (OPS-25 D3) ──────────────
# One binary serves every gate (`cargo build -p lakehouse-api`, rust/Dockerfile),
# and 21 of the 25 gates create connectors, run pipelines and read back through
# the routes below, so these are shared even though one feature looks like its
# only user:
#   - docker-compose.yml, .env.example (the stack every gate starts);
#   - .github/* (the workflows), scripts/* (including scripts/ci/*);
#   - rust/migrations/* (the schema every gate reads), rust/Cargo.toml,
#     rust/Cargo.lock, every crate's Cargo.toml, rust/Dockerfile,
#     rust/entrypoint.api.sh, rust/rust-toolchain.toml;
#   - dagster/Dockerfile, dagster/pyproject.toml, dagster/dagster.yaml,
#     dagster/dispar_orchestrate/definitions.py and every Dagster module not
#     listed above;
#   - ops/fixtures/*, ops/gates/* (the gate registry and the log helper every
#     gate calls), ops/oidc-mock/* (built by most gates), ops/smtp-ca/* (mounted
#     into the API), ops/backups/* (mounted into ClickHouse), ops/init-env.sh;
#   - in the API: lib.rs, main.rs, state.rs, config.rs, policy.rs
#     (POLICY_TABLE), policy_engine.rs, sql_rewrite.rs, routes/mod.rs (the
#     router), routes/support.rs, routes/auth.rs, routes/identity.rs,
#     routes/connectors.rs, routes/pipelines.rs, routes/query.rs,
#     routes/governance.rs, upstream_error.rs; and all of lakehouse-core,
#     lakehouse-store/src/ except the modules listed above, lakehouse-auth,
#     lakehouse-iceberg/src/, lakehouse-clickhouse, lakehouse-dagster;
#   - any other ops/* or rust/* path.
