## Why

The console sends no CSP. `BI-16` part B's image and web cards check the
address as written against the allowed content sites
(`src/lib/type-b.ts` `siteAllowed`, `src/features/dashboards/content-cards.tsx:27,42`),
but the browser follows a redirect from an allowed site anywhere. With
`img-src` and `frame-src` limited to those sites the browser itself refuses
the redirect target. A policy also removes whole classes of injection
(inline script, foreign script, `object`, `base` hijack) as a second line
behind `escapeHtml` (`#199` round O).

## What exists

- `src/proxy.ts` (Next 16's middleware file): matches `/embed/:path*` only
  and sets `Content-Security-Policy: frame-ancestors …` from
  `POST /api/embed/frame` (`SEC-12`), failing closed to `'none'`.
- Content sites: `GET /api/settings/reporting` (`routes::settings`,
  `routes/mod.rs:1207`), `contentSites: string[]` of `https://host[:port]`,
  at most 50, one list per deployment; reading needs a sign-in
  (`src/services/contracts/settings.ts:28-32`).
- `src/components/app-shell/react-grab-dev.tsx`: a dev-only helper, opt-in.
- `next.config.ts`: no `headers()`.

## Decisions (planner)

1. **One policy builder**, a pure function in `src/lib/csp.ts`, unit-tested,
   used by `src/proxy.ts` for every page (the matcher widens to all routes
   except `/_next/static`, `/_next/image`, `/favicon.ico` and `/api`, which
   the API answers). The embed path keeps its `frame-ancestors` logic,
   merged into the same builder.
2. **The policy** (production):
   `default-src 'self'; script-src 'self' 'nonce-<n>' 'strict-dynamic';
   style-src 'self' 'unsafe-inline'; img-src 'self' data: blob: <sites>;
   frame-src <sites or 'none'>; connect-src 'self'; font-src 'self' data:;
   object-src 'none'; base-uri 'self'; form-action 'self';
   frame-ancestors 'none'` (embed pages: their own list).
   - `style-src 'unsafe-inline'` is a stated exception: React, Radix and
     ECharts set inline `style` attributes, which a nonce cannot cover.
     Say so in a comment; it does not allow script.
   - A fresh nonce per request (`crypto.getRandomValues`, base64), passed to
     the page the way Next 16 documents for App Router CSP (read the guide in
     `node_modules/next/dist/docs/` for the installed version, and follow
     it: a request header the app reads, so Next's own inline scripts carry
     it). Pages that use the nonce render dynamically; name any page this
     changes from static.
   - `next dev` needs `'unsafe-eval'` and a websocket `connect-src`; add
     them only when `NODE_ENV === "development"`, in the builder, with a
     test that production never has them.
3. **Content sites in `img-src` and `frame-src`.** The proxy reads them from
   `GET /api/settings/reporting` with the request's cookie forwarded, a 3 s
   timeout (as `ASK_TIMEOUT_MS`), cached in memory for 60 s (one list per
   deployment, so one cache entry). Fail closed: no session, an error or a
   timeout gives no extra site (`img-src 'self' data: blob:`,
   `frame-src 'none'`). Every site goes through a validator
   (`https://host[:port]`, nothing else) before it enters the header, so a
   stored value can never inject a directive (`;`, space, quote).
   Embed pages: `POST /api/embed/frame` also returns the board's content
   sites when the token is valid (Rust, `routes/embed*`; the same list the
   board's cards check), and the embed policy uses them.
4. **Not report-only.** The point is enforcement. The reviewer checks the
   console in a real browser before merge (T5).
