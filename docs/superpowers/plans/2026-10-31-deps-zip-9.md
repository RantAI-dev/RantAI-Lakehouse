# zip 9: the upload and export code builds on the new `ZipFile::name()`

Dependabot #273 bumps `zip` from 8.6.0 to 9.1.2 in `/rust`, and CI's Rust build fails on it.
In zip 9, `ZipFile::name()` returns `Result<Cow<str>, ZipError>`, because member names are now
decoded (CP437 included) and decoding can fail. This plan replaces #273: the developer bumps
`zip` on a fresh branch from `main`, so the lockfile is regenerated against today's `main`, and
fixes the call sites. Base: `main` at `6711ad65`.

Planner: Claude Opus. Developer: a different agent (`AGENTS.md`). The developer does not change
a decision below. If the code disagrees with the plan, stop and report it.

## 1. Decisions (made; do not change)

- **D1. The version.** `zip = { version = "9.1", default-features = false, features =
  ["deflate"] }` in both places in `rust/crates/lakehouse-api/Cargo.toml` (`:152` and `:203`),
  with the features unchanged. Update only `zip` in the lockfile: `cargo update -p zip`. Nothing
  else may move. If another crate also changes in `Cargo.lock`, stop and report it.
- **D2. An unreadable member name refuses the upload.** In `upload_formats.rs`, a `name()` error
  maps to `Refusal::NotZip`, the refusal this file already gives for an entry it cannot read
  (`by_index_raw` at `:1066-1068`).
  - Read the name once per entry into a local (`let name = file.name().map_err(|_err|
    Refusal::NotZip)?;`) and use it at `:1069`, `:1103`, `:1106` and `:1111`.
  - Add a comment citing this plan: zip 9 decodes names, a name it cannot decode is refused,
    and the zip error text never reaches the response (`AGENTS.md` principle 4).
- **D3. Elsewhere, fix only what fails to compile.** `src/export.rs`, `tests/query_download.rs`
  and `tests/dashboard_export.rs` also use `zip`.
  - Fix what fails to compile with the same rule.
  - In test code, `.expect("…")` with a reason is allowed, because it is under
    `#[cfg(test)]` or in `tests/`.
  - Do not refactor anything else.
- **D4. No behaviour change** beyond D2. In particular, the limits, the `__MACOSX/` skip and the
  refusal order stay as they are.
