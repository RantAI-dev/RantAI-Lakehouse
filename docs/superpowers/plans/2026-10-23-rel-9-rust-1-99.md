## Machine notes

- A new toolchain recompiles every crate in the shared `CARGO_TARGET_DIR`,
  so budget for one cold build. `rustup toolchain install 1.99.1 1.99.0
  --profile minimal -c rustfmt,clippy` first. Never `cargo clean`.
- Disk is about 140 GB free; a second toolchain's artifacts add about
  10-15 GB. If free space drops under 30 GB, stop and report.
