## Why

A lineage page exists but no chart links to it.

## What users get

From any chart, see which tables and source systems its numbers come from.

## Target specs

"Today" is `main` at `47a826d`, read from the code, not tested. A target is either a competitor's documented number (named under Benchmark) or marked *(proposed)*: the planner's number, which the product owner confirms or changes on the feature page before the plan is written.

| Capability | Today | Target |
| --- | --- | --- |
| Link | Lineage page exists, not linked from dashboards | 'Where does this come from' on every chart opens its lineage |
| Depth | n/a | Chart → saved query or metric → Gold → Silver → Bronze → connector or upload; columns when DATA-13 is done |
| Freshness | n/a | Each step shows when it was last refreshed |
| Impact | n/a | From a table, list the charts and dashboards that use it |

## Benchmark

Tableau Catalog (Enterprise); Metabase dependency graph (Pro+). A natural strength for a lakehouse.

## Acceptance checklist

Run on a running console by the product owner. A step not performed is never a pass.

- `BI-14-AC1` A chart's lineage reaches the connector its data came from
- `BI-14-AC2` A Gold table lists the dashboards that use it
- `BI-14-AC3` A user without the permission is refused, and a failure shows an honest message (principles 2 and 4)

## Not included

- Anything not in the Target table.
