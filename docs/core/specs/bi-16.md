## Why

Tables are always grouped and capped at 100 rows, there is no pivot table, KPI comparison, progress bar, histogram, Gantt or world map.

## What users get

Every chart type the two competitors offer, minus those the owner dropped.

## Target specs

"Today" is `main` at `47a826d`, read from the code, not tested. A target is either a competitor's documented number (named under Benchmark) or marked *(proposed)*: the planner's number, which the product owner confirms or changes on the feature page before the plan is written.

### Part A: Tables and KPI cards

Roadmap phase 1, size M. Raw-row tables, pivot tables with totals, and KPIs that compare.

| Capability | Today | Target |
| --- | --- | --- |
| Raw table | Always grouped, at most 100 rows | Raw rows paged through the whole result; column formats, widths, hide/reorder, wrapped text, links and images in cells |
| Pivot table | None | Rows, columns and values; totals and subtotals; collapse groups; up to 10,000 cells shown *(proposed)* |
| KPI | Plain big number | Value with comparison to the previous period or a goal, as amount and percent, coloured up/down, with a sparkline (Metabase trend) |
| Record detail | Drill-down list only | A one-record view with every field and next/previous |

### Part B: Simple chart types we lack

Roadmap phase 3, size M. Progress, histogram, bullet, image and web cards.

| Capability | Today | Target |
| --- | --- | --- |
| Progress bar | None | Value against a goal |
| Histogram | None | Automatic bins on a number column (with BI-10) |
| Bullet graph | None | Value, target and bands |
| Image and web-page cards | None | An image by URL and an embedded page from an admin allowlist of domains |
| Coverage check | n/a | Every type in the Metabase list above exists, except those the owner dropped |

### Part C: Advanced chart types and maps

Roadmap phase 6, size L. Gantt charts, world maps with your own boundaries, spatial analysis.

| Capability | Today | Target |
| --- | --- | --- |
| Gantt chart | None | Start, end and group; today line |
| Maps | Jakarta and Indonesia maps only | World and country maps; pin, region and grid maps; upload GeoJSON boundaries up to 50 MB *(proposed)* |
| Spatial analysis | None | Distance between points, points within an area, spatial joins (Tableau spatial functions) |
| Custom chart plugins | None | A documented plugin interface for a custom visual (Metabase custom visualizations) |

## Benchmark

Metabase: table, pivot table, number, trend, detail, progress, gauge, line, bar, combo, area, row, waterfall, scatter/bubble, pie/donut, funnel, maps, sankey, box plot. Tableau Show Me: 24 types including Gantt, bullet, histogram, maps.

## Acceptance checklist

Run on a running console by the product owner. A step not performed is never a pass.

- `BI-16-AC1` A pivot with two row levels shows subtotals and a grand total
- `BI-16-AC2` A KPI shows this month against last month with a sparkline
- `BI-16-AC3` A raw table pages through 50,000 rows
- `BI-16-AC4` An uploaded province boundary file colours a region map
- `BI-16-AC5` A Gantt chart shows tasks by start and end
- `BI-16-AC6` A user without the permission is refused, and a failure shows an honest message (principles 2 and 4)
