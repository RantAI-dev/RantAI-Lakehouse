## Why

Each chart reads one table or one SQL source.

## What users get

Overlay two questions on one chart, such as visitors next to occupancy.

## Target specs

"Today" is `main` at `47a826d`, read from the code, not tested. A target is either a competitor's documented number (named under Benchmark) or marked *(proposed)*: the planner's number, which the product owner confirms or changes on the feature page before the plan is written.

| Capability | Today | Target |
| --- | --- | --- |
| Series from several questions | One source per chart | Up to 5 questions on one chart *(proposed)*, matched on a shared dimension |
| Axes | n/a | A second Y axis when units differ |

## Benchmark

Metabase Visualizer: combine several questions on one chart. Tableau data blending.

## Acceptance checklist

Run on a running console by the product owner. A step not performed is never a pass.

- `BI-13-AC1` Visitors (bars) and occupancy rate (line, right axis) by month on one chart
- `BI-13-AC2` A user without the permission is refused, and a failure shows an honest message (principles 2 and 4)
