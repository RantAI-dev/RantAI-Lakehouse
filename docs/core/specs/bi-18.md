## Why

Dashboards have one hard-coded year filter, no click-through outside drill-down, no tabs and no phone layout. Both competitors have all of this on every plan.

## What users get

Dashboards that filter, click through and lay out like Metabase and Tableau.

## Target specs

"Today" is `main` at `47a826d`, read from the code, not tested. A target is either a competitor's documented number (named under Benchmark) or marked *(proposed)*: the planner's number, which the product owner confirms or changes on the feature page before the plan is written.

### Part A: Filters that work like other BI tools

Roadmap phase 1, size L. Filter any dashboard by date, number or text, with linked lists.

| Capability | Today | Target |
| --- | --- | --- |
| Date filters | Only a year filter, hard-coded to a column named tahun, not saved | Specific date, range, before/after, relative (last/next N days, weeks, months, quarters, years; this/previous period), month-year, quarter-year (Metabase's set) |
| Number filters | None | Equal, not equal, between, greater/less than |
| Text and category filters | None | Is, is not, contains, does not contain, starts with, ends with; single or multiple values |
| Linked filters | None | A filter limits another's values (choosing a province narrows the city list) |
| Long value lists | Capped at 200 values, no search | Search inside the list; values loaded on demand, no cap on what can be found |
| Filters per dashboard | 1 | Up to 20 *(proposed)* |
| Defaults | An editor's ad-hoc filter silently becomes the shared default, also for public and embed viewers | Defaults change only when someone saves them; a viewer's choice stays with the viewer and in the URL |
| SQL-source charts | Filter values from Gold tables only | Filters apply to SQL-source charts through parameters (QS-5) and their values come from any table |
| Required and locked | None | A filter can be required, or locked in embeds (BI-26) |

### Part B: Click-through and drill-down everywhere

Roadmap phase 1, size M. Click any point to drill down, open another dashboard or a link.

| Capability | Today | Target |
| --- | --- | --- |
| Drill-down | Not for nine chart types or SQL-source charts; 100-row cap | Every chart type and SQL-source charts; the drilled list pages through all rows |
| Click destinations | None | Another dashboard (passing the clicked value to its filter), a saved query, or a URL with the value inserted (Metabase custom destinations) |
| Cross-filtering | None | Clicking a chart value filters the other charts on the dashboard |
| Auto-refresh | Browser only, not saved | Saved per dashboard: 1, 5, 10, 15, 30 or 60 minutes (Metabase's choices) |
| Full-screen | A page overlay | Real full-screen with a dark theme option, for wall displays |

### Part C: Layout and organisation

Roadmap phase 3, size L. Tabs, phone layouts, version history and a trash.

| Capability | Today | Target |
| --- | --- | --- |
| Tabs | None | Tabs inside a dashboard; filters apply across tabs or to one |
| Phone and tablet | Tiles scale but do not stack | Tiles stack into one column under 640 px; an optional separate phone layout (Tableau device layouts) |
| Sections | None | Headings, text and dividers; collapsible sections |
| Reports with charts | None | A written page mixing text and live charts (Tableau Stories, Metabase documents) |
| Templates | None | Save a dashboard as a template; start a dashboard from one |
| Finding things | Last visited only; search on the browse page only | Favourites, recent items, and search from every page |
| Version history | None | Last 15 versions with author and time, revert to any (Metabase) |
| Trash | None | Deleted dashboards and charts restorable for 30 days (Metabase) |
| Personal space | None | A private space for drafts per user |
| Duplicate | Filters dropped; fails on the built-in board | Copies tiles, filters and layout, on any dashboard |

## Benchmark

Metabase dashboard filters, click behaviour, tabs (all plans). Tableau filters, actions, device layouts (all editions).

## Acceptance checklist

Run on a running console by the product owner. A step not performed is never a pass.

- [ ] Every Target row above works as written
- [ ] A relative 'last 30 days' filter saved on a dashboard still means the last 30 days tomorrow
- [ ] Choosing a province limits the city filter
- [ ] A viewer's filter change does not change what the next viewer sees
- [ ] Clicking a bar opens another dashboard filtered to that value
- [ ] On a 390 px wide phone the tiles stack in one column
- [ ] A deleted dashboard is restored from the trash
- [ ] A user without the permission is refused, and a failure shows an honest message (principles 2 and 4)
