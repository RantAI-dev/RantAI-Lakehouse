## Why

Numbers cannot be binned, values cannot be grouped, and there are no drill hierarchies.

## What users get

Bin numbers, group values into your own categories, and drill through a hierarchy.

## Target specs

"Today" is `main` at `47a826d`, read from the code, not tested. A target is either a competitor's documented number (named under Benchmark) or marked *(proposed)*: the planner's number, which the product owner confirms or changes on the feature page before the plan is written.

| Capability | Today | Target |
| --- | --- | --- |
| Number bins | None | Automatic, or a set count (10, 50, 100) or width |
| Coordinate bins | None | Latitude/longitude binning for grid maps |
| Custom groups | None | Group selected values under a new name, with 'other' |
| Hierarchies | None | An ordered set of columns (country > province > city) to drill through, defined once per table |

## Benchmark

Tableau: bins, groups, hierarchies. Metabase: automatic binning (10, 50, 100 bins) and coordinate binning.

## Acceptance checklist

Run on a running console by the product owner. A step not performed is never a pass.

- `BI-10-AC1` Age binned into 10-year groups
- `BI-10-AC2` Three provinces grouped as 'Java' chart as one bar
- `BI-10-AC3` Clicking a country drills to its provinces
- `BI-10-AC4` A user without the permission is refused, and a failure shows an honest message (principles 2 and 4)
