## Why

The saved number format is ignored, numbers round to whole numbers, there is one fixed palette, and no axis, label, reference line, forecast or clustering options.

## What users get

Charts formatted to the competitors' level, plus forecast and clustering.

## Target specs

"Today" is `main` at `47a826d`, read from the code, not tested. A target is either a competitor's documented number (named under Benchmark) or marked *(proposed)*: the planner's number, which the product owner confirms or changes on the feature page before the plan is written.

### Part A: Chart formatting

Roadmap phase 3, size L. Numbers, colours, axes and labels formatted as you want.

| Capability | Today | Target |
| --- | --- | --- |
| Number formats | Saved format ignored; whole numbers only | Decimals (0–10), thousands separator, currency (any ISO code, symbol or code), percent, scientific, compact (1.2 K, 3.4 M), prefix and suffix; per column and per chart |
| Dates | Not checked | Date and time styles, 12/24-hour, abbreviations |
| Colours | One fixed palette | Colour per series, palettes, and colour by value; an admin brand palette |
| Axes | None | Titles, min/max, log scale, show/hide, label rotation; second Y axis |
| Data labels | None | Values on points and bars, with format and overlap avoidance |
| Conditional formatting | None | Tables and KPIs: colour cells by rule or colour range |
| Reference lines | None | Goal line, average/median line, trend line (linear), bands |
| Annotations and tooltips | None | Notes on a point; choose tooltip fields |
| Themes and fonts | Follows app dark mode | Light and dark themes per dashboard; font choice from an admin list |

### Part B: Forecasting and clustering

Roadmap phase 6, size M. A forecast on a time series and clusters on a scatter chart.

| Capability | Today | Target |
| --- | --- | --- |
| Forecast | None | Exponential smoothing with trend and seasonality, horizon set by the user, with a 95% prediction band (Tableau) |
| Clustering | None | k-means on a scatter chart, k automatic or chosen (Tableau) |
| Honesty | n/a | Says when there is too little data to forecast, instead of drawing a line (principle 2) |

## Benchmark

Metabase visualization settings (all plans). Tableau formatting, analytics pane: reference lines, trend lines, forecast (exponential smoothing), clustering (k-means).

## Acceptance checklist

Run on a running console by the product owner. A step not performed is never a pass.

- `BI-17-AC1` A revenue column shows Rp 1,2 M with two decimals when so set
- `BI-17-AC2` Bars take the chosen colours
- `BI-17-AC3` A goal line at 1,000 appears on a bar chart
- `BI-17-AC4` A 24-month series shows a 6-month forecast with a band
- `BI-17-AC5` A scatter chart colours points by cluster
- `BI-17-AC6` A user without the permission is refused, and a failure shows an honest message (principles 2 and 4)
